agent-hierarchy — role & flow map

Six roles, each on a model priced for what that role actually does. Reasoning tiers read and judge; they never execute. The Orchestrator keeps every role in its lane.

Tiers — small work stays cheap

Trivial

Orchestrator alone. One blind edit, no verification — a typo, a config value. No dispatches at all.

Determined

Implementor → Reviewer. The request itself is the spec; no design choices remain. The Architect is skipped, review is not.

Everything else

Architect → spec → Implementor → Reviewer. Ultra-Advisor is inserted only when a trigger fires: unresolved fork, low confidence, stalled review loop, outsized blast radius, or the user says it matters.

Comms — files, roster, tier (0.29.0)

Message files

Every dispatch rides a request file and every report a response file (msg.mjs new, fixed ## [N] skeleton, flat frontmatter) under the hierarchy runtime dir; in-band only the pointer [hierarchy-msg <path>] travels. Gates deny a role dispatch without a valid request pointer and block a role's final message without the matching response pointer. Saves context only if readers index and Read selectively.

Peer roster

peers.jsonl is ground truth for live peer sessions — up/down from the peer's own hooks (pid liveness), seen/briefed from ListAgents and sent briefs.

Routing preference

One AskUserQuestion per session — peers, subagents, or prefer-peers (default) — asked once before the first roster dispatch, then enforced silently and one-shot per (session, role); the identical re-issue always passes. msg.mjs route <value> records it; a config route key skips the ask.

Tier rule

Dispatching an advisor role at or below the session's own model tier is consulting yourself at double cost — denied once unless the request file states a reason: (context, second-opinion, parallel).

Flow control — who advances the chain

handoffs: "auto" (default)

The Orchestrator performs handoffs itself and reports as it goes.

handoffs: "confirm"

Before each reasoning-role dispatch the user is asked — Dispatch / Do it inline / Skip — and skipping states what goes unverified. Legwork is never gated.

Switch anytime

Both directions, mid-session, in plain words — “ask me before handoffs”, “stop asking” — or /hierarchy flow. Takes effect immediately.
